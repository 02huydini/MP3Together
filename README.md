# A mod for Client to play their own music within the Host server

### Mod requirement for CasualtiesMP
<u>Host, and Client</u> have this mod.
Major part of the mod still work without CasualtiesMP.

### Core Problem
Client can't play their music in Host server.

### What will this mod do?
Let Client play their own music, alongside unesserccery features.

### Installation
Extract MP3Together folder, place it into "...\BepInEx\plugins\" folder.
